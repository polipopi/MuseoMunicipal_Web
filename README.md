# Museo Municipal de Guayaquil

## Descripción
Landing page informativa sobre el Museo Municipal de Guayaquil y sus actividades culturales, basada en una visita y encuestas realizadas a sus visitantes durante la obra de teatro *Aurora Gloriosa*.

## Objetivo
Facilitar el acceso a información sobre el museo, sus eventos y actividades culturales.

## Secciones
- **Inicio:** presentación del museo.
- **Museo:** información general.
- **Eventos:** actividades culturales y obra teatral.
- **Galería:** fotografías de la visita.
- **Encuestas:** opiniones de los visitantes.

## Plantilla seleccionada
Se eligió **Phantom**, de [HTML5 UP](https://html5up.net/phantom), por su diseño visual, adaptable y fácil de personalizar.

## Tecnologías
HTML5, CSS3, Git y GitHub.
